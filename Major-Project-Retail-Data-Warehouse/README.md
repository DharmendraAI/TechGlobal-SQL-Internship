# Major Project: Retail Data Warehouse

## Overview

This project implements a retail data warehouse workflow for organizing retail data and supporting analytical queries.

## Key Components

* ETL pipeline for data loading and transformation.
* Data warehouse tables and dimensional relationships.
* Foreign key integrity validation.
* Revenue calculation accuracy checks.
* ROLLUP and CUBE analytical queries.
* Automated testing using pytest.

## Technologies

* Python
* SQL
* PostgreSQL
* pytest
* GitHub

## Testing

The project includes automated tests for table data availability, foreign key integrity, revenue accuracy, roll-up totals, and query performance.
