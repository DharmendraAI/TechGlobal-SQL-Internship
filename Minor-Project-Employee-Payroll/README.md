# Minor Project: Employee Payroll SQL Database

## Overview

This project focuses on designing a relational database to manage employee payroll information.

## Objectives

* Manage employee and department records.
* Store salary and attendance details.
* Maintain payroll deductions.
* Use primary keys, foreign keys, and data integrity constraints.
* Write SQL queries for payroll calculations and reporting.

## Technologies

* SQL
* Relational Database Management System

## Project Contents

This folder contains the SQL scripts, database schema, sample data, and supporting project documentation.
